## 1. Module Purpose

My News is the personal workspace for each user — providing a personalized news feed, activity tracking, and contribution tools. It is designed to deepen engagement, build habits, and drive Pro/Enterprise upgrades through AI features and unlimited access.

**Purpose:** Personal workspace for personalized news, activities, contributions, and premium engagement.

---

## 2. Submenus

### 2.1 My News (My Sector Trade News)
**Purpose:** Personalized news feed based on selected sectors, countries, companies, and leaders.

**Screen Components:**

| Section | Description |
|---------|-------------|
| Header | Welcome message, Refresh button, Last updated timestamp |
| News Cards | Thumbnail, Headline, Summary, Read time, Save, Like, Comment, Share |
| My Interests Panel | Topic/sector interests with "Edit Interests" CTA |
| Quick Stats | News read count, Saved count, Following count, Streak counter |
| AI News Summary (Pro) | AI-generated personalized news digest |
| Right Sidebar | Trending topics, Alerts, Reports, Events |

**Revenue:**
| Tier | Features |
|------|---------|
| Free | Limited feed |
| Pro | AI News Summary + unlimited feed |
| Enterprise | Custom dashboards |

---

### 2.2 My Activities
**Purpose:** Dashboard of all user engagement actions.

**Activity Tracking:**
| Activity | Description |
|---------|-------------|
| Dashboard | Likes, Comments, Shares, Bookmarks, Following, Reading hours |
| My Likes | All articles the user has liked |
| My Comments | All user's comment history |
| My Bookmarks | Saved/bookmarked articles |
| My Shares | Articles shared by the user |
| My Following | Followed authors, companies, leaders |
| Recently Viewed | Last-read article history |

**My Trade-News Analytics (Pro):**
- Reading trends over time
- Engagement score
- AI-powered reading insights
- Export analytics as PDF

**Revenue:**
- Pro analytics unlock
- AI reading insights

---

### 2.3 My Contribution
**Purpose:** User's publishing and content contribution workspace.

**Dashboard Metrics:**
| Metric | Description |
|--------|-------------|
| Published | Total published articles |
| Drafts | In-progress articles |
| Pending Review | Submitted, awaiting approval |
| Rejected | Articles needing revision |
| Total Views | Cumulative article views |

**Features:**
- Content performance analytics per article
- AI content suggestions (Pro)
- Draft editor

**Revenue:**
- Featured articles (paid placement)
- SEO tools (Pro feature)
- Sponsored publishing
- Enterprise content campaigns

## 4. Monetization Strategy

| Monetization | Implementation |
|--------------|----------------|
| Upgrade Banners | Persistent Pro/Enterprise conversion prompts |
| AI+ CTA | AI summary locked for free users |
| Premium Analytics | Pro-gated reading insights |
| Unlimited Bookmarks | Limited on free, unlimited on Pro |
| Sponsored Reports | Contextual report recommendations |
| Enterprise Subscription CTA | Team/corporate access promotion |

---

## 5. User Journey

```
My News → Read Personalized Feed → Save Articles → Check Activities
→ View Reading Analytics → Hit AI Lock → Upgrade to Pro
→ Contribute Articles → Get Featured → Upgrade to Enterprise
```

---

## 6. Engagement & Retention Features

- **Streak Counter:** Encourages daily news reading habits
- **Quick Stats:** Gamifies engagement with visible metrics
- **My Interests Panel:** Keeps feed highly personalized
- **Activity Dashboard:** Builds sense of investment in the platform
- **AI News Digest:** High-value Pro feature that drives upgrades
