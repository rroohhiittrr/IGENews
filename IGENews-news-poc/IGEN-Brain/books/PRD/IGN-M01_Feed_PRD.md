# IGN-M01 · Feed Module — Product Requirement Document

> **Module:** Feed (Personalized News Feed)
> **Parent:** India Global News (iGEN News)
> **Source:** `books/UX/pages/feed pages/IGEN_Feed_Mega_Menu_Submenu_Revenue_Focused_Document.docx`

## 1. Module Purpose

The Feed module provides personalized, intelligence-driven news across Sectors, Industries, Countries, Leaders, and Readers. It encourages subscription upgrades and premium engagement through locked AI features and upgrade CTAs.

---

## 2. Feed Categories & Submenus

### 2.1 Sector Feed
| Submenu | Purpose |
|---------|---------|
| My Sector | Relevant news based on user's selected sectors |
| All Sector | News across all 50 sectors |
| Sector Intelligence | Deep intelligence reports per sector |

### 2.2 Industry Feed
| Submenu | Purpose |
|---------|---------|
| My Industry | Personalized news for user's chosen industries |
| All Industry | News across all 1,350+ industries |
| Industry Intelligence | Intelligence reports per industry |

### 2.3 Country Feed
| Submenu | Purpose |
|---------|---------|
| My Country | Country-specific news for user's home/selected country |
| All Country | Global news from 195 countries |
| Country Intelligence | Bilateral trade & investment intelligence |

### 2.4 Leader Feed
| Submenu | Purpose |
|---------|---------|
| My Leader | News about leaders the user follows |
| All Leader | Global executive and leader news |
| Leader Intelligence | Executive movement, M&A, board changes |

### 2.5 Reader Feed
| Submenu | Purpose |
|---------|---------|
| My Reader | User's personalized reading history and recommendations |
| All Reader | Platform-wide popular reads |
| Reader Intelligence | Reading analytics and insights (Pro) |

---

## 3. Screen Components (All Feed Submenus)

| Component | Description |
|-----------|-------------|
| Hero Banner | Featured story with image, headline, CTA |
| Top Stories | Editorial picks for the submenu context |
| Personalized / Latest News Feed | Real-time news stream |
| Search & Filters | Keyword, sector, country, date filters |
| Trending Topics | Dynamic trending list |
| Recommended Reports | Premium report suggestions |
| AI Intelligence Preview | Locked for free users — upgrade prompt |
| Upgrade Banner | Reader / Leader / Corporate upgrade CTAs |
| Related Premium Pages | Cross-sell to Company, Leader, Expert pages |
| Newsletter Signup | Email subscription for the feed category |
| Sponsored Content | Paid native content placements |

---

## 4. Revenue Opportunities

| Revenue Stream | Implementation |
|----------------|----------------|
| Subscription Plans | Free/Pro/Enterprise tiers with gated AI content |
| AI Plus Intelligence | Locked preview drives upgrades |
| Premium Intelligence Reports | Contextual report recommendations |
| Sponsored Listings | Native sponsored stories in feed |
| Cross-sell | Company, Leader, Expert, Sector & Country pages |
| Sticky Upgrade CTA | Persistent conversion element |
| Contact Sales CTA | Enterprise sales conversion |

---

## 5. User Journey
```
Feed Menu → Select Category (Sector/Country/Leader) 
→ Select Submenu (My/All/Intelligence)
→ Read Articles → Hit AI Lock → Upgrade Prompt
→ Upgrade to Pro/Enterprise OR Subscribe Newsletter
```
